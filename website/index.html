Pourquoi nous

Pourquoi choisir NAVY plutot qu'un autre navigateur ?

NAVY mise sur un angle simple: moins de bruit, moins de collecte, plus de controle local.

Un navigateur plus lisible

La barre principale reste compacte, les commandes utiles sont directes et l'espace principal appartient aux pages web.

  • Interface resserree avec onglets et favoris ranges
  • Mode optimisation pour alleger le chargement
  • Boutons visuels rapides sans interface surchargee
Le coffre reste chez toi

Les identifiants sont sauvegardes sur la machine, chiffres et deverrouilles avec un mot de passe maitre.

  • Pas d'obligation de compte distant
  • Ajout automatique et ajout manuel possibles
  • Auto-remplissage base sur l'URL visitee
Protection plus franche

NAVY coupe les regies pub et les trackers les plus frequents au niveau reseau, avec des stats visibles.

  • Blocage pub et trackers
  • Mode opti pour les ressources lourdes
  • Reglages separables suivant tes besoins
RGPD et confidentialite

Ce que NAVY fait et surtout ce que NAVY ne fait pas

Le principe retenu ici est la sobriete de donnees: on collecte le minimum, idealement rien.

Pas de collecte marketing

  • Pas de profil publicitaire cree par NAVY.
  • Pas de vente ou partage de donnees personnelles a des tiers par NAVY.
  • Pas de tableau de bord analytics utilisateur active par defaut dans l'application.

Traitement local par defaut

  • Les mots de passe restent en local sur la machine.
  • Le coffre-fort est chiffre et protege par mot de passe maitre.
  • Les favoris et preferences sont stockes localement pour ton usage.

Transparence utilisateur

  • Tu choisis le moteur de recherche dans les parametres.
  • Tu peux activer ou couper le bloqueur, le mode opti et le gestionnaire de mots de passe.
  • Le projet peut etre audite car le code source est public sur GitHub.

Important: le navigateur ouvre des sites tiers comme Google, Qwant ou Bing si tu les choisis comme moteur. Ces services appliquent ensuite leurs propres politiques de confidentialite. NAVY n'ajoute pas une collecte marketing supplementaire par-dessus.

FAQ

Questions frequentes

Les points que les utilisateurs regardent le plus avant l'installation.

Pourquoi Windows affiche parfois un avertissement ?

Le message SmartScreen apparait surtout quand une application n'a pas encore de signature code reconnue ou pas assez de reputation de diffusion. Ce point ne se retire pas proprement par une ligne de code.

Est-ce que NAVY remplace mon moteur de recherche ?

NAVY laisse le choix du moteur dans les parametres. La barre principale reste volontairement plus simple et utilise ensuite le moteur selectionne.

Ou sont stockes les mots de passe ?

Dans le coffre-fort local du navigateur, chiffre sur la machine. Ils ne partent pas dans un cloud NAVY.
